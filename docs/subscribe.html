👑 영농대행업자 구독

여러 농가의 농지에 작업 기록을 직접 남길 수 있는 마스터 농부 등급. 영농대행업·농기계 임대업 등 다수 농가를 상대하는 분께 적합합니다.

구독 절차

  1. 농작이 앱에서 영농대행업자 등록 → 업자코드 발급 (가입 즉시 3개월 무료 체험 시작)
  2. 체험 기간 중 농가에게 업자코드 전달 → 농가가 입력하면 해당 농장 접근 가능
  3. 체험 종료 전 아그로이드에 결제 안내 요청 (이메일 또는 카카오톡 채널)
  4. 안내된 계좌로 입금 (입금자명은 가입 이메일 앞부분으로 기재) → 운영자가 입금 확인 후 구독 연장

요금

※ 2026 원년 회원은 평생 50% 할인. 첫 가입 시 3개월 무료 체험 (자동 결제 없음 — 입금하지 않으면 자연 종료).

시즌권 (8개월, 3~10월 농번기)₩65,000 → 원년 ₩32,500
월권 (30일)₩10,000 → 원년 ₩5,000
연권 (365일)₩98,000 → 원년 ₩49,000

프로모션

  • 2026 원년 회원 평생 50% 할인 — 가입 연도가 2026 인 영구 자격. 재구독·갱신 시 동일 할인 유지.
  • 첫 3개월 무료 체험 — 의뢰 농가·멤버 제한 없는 풀 기능. 자동결제 없어 이탈 위험 0.
  • 의뢰 농가 추천 보상 — 의뢰 농가가 별도 프로농부 결제 전환 시 1개월 무료 연장 (10명 달성 시 6개월).
  • 농협·작목반 단체 — 10계정 이상 묶음 결제 시 30% 추가 할인.

주요 혜택

  • 여러 농가의 농지 정보 접근·수정 (농가가 권한 부여한 농장만)
  • 농가별 작업 기록 통합 관리
  • 구독 만료 시 모든 농장 접근 자동 차단 (보안)

💬 구독 문의

현재 결제는 계좌이체 수동 입금으로만 받습니다. 자동결제가 없어 체험 후 입금하지 않으면 자연 종료되며 카드 정보 등록도 필요 없습니다. 이용자 규모에 따라 토스페이먼츠·카카오페이 도입을 검토할 예정입니다.
