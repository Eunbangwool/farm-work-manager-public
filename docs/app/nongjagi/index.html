📱 안드로이드 앱 설치

더 빠르고 편한 앱 버전을 설치할 수 있어요. (갤럭시·기타 안드로이드 동일)
  1. 1
    다운로드 시작 아래 [다운로드 시작] 버튼을 누르면 APK 파일이 다운로드됩니다.
  2. 2
    파일 열기 다운로드 알림(또는 [내 파일] → 다운로드 폴더)에서 Farmwork.apk 를 탭하세요.
  3. 3
    출처 허용 (최초 1회) "이 출처의 앱 설치 허용" 안내가 뜨면 [설정] 으로 이동 → 토글 ON → 뒤로가기.
  4. 4
    설치 → 열기 [설치] 탭 → 잠시 후 [열기] 가 나오면 앱 실행. 같은 Google 계정으로 로그인하면 데이터가 그대로 보입니다.
※ 'Play 프로텍트' 경고가 나와도 [무시하고 설치] 가능 — 농작이 자체 빌드라 안전합니다.
