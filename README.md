# farm-work-manager-public

농작이(Farmwork) 앱의 **공개 배포 채널**입니다.

- **앱 설치 파일(APK)**: [Releases](https://github.com/Eunbangwool/farm-work-manager-public/releases) 에서 배포됩니다.
  앱 내 업데이트 확인은 이 저장소의 `releases/latest` 를 사용합니다.
- **웹/문서 사이트**: `docs/` 가 GitHub Pages 로 서빙되며 커스텀 도메인
  [www.sangwolnongsan.com](https://www.sangwolnongsan.com) 에 연결됩니다.
  (이용약관·개인정보처리방침·구독 안내·계정 삭제·사용 설명서·app-ads.txt 등)

> 앱 **소스 코드는 비공개 저장소**에서 관리됩니다. 이 저장소에는 공개되어야 하는
> 문서와 배포물만 포함됩니다.
